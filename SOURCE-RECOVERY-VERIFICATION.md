# Восстановление источников «Март-Трейд» — 21.09.2026

## Причина регрессии

1. `parseConnection` запрещал две связи `(section, dataset)` даже для разных листов и требовал одинаковые колонки для всех связей набора.
2. Первичный ключ `mart_source_links(section,dataset)` разрешал только одного поставщика показателя во всей базе. Флаг `priority` удалял совпадающие связи других подключений.
3. Google-адаптер читал лишь первую связь набора. Компоновщик аварийно завершался при повторном назначении, сбрасывал `receivables` и заменял успешные данные пустым несинхронизированным снимком.
4. Общая кнопка обновления читала сохранённые снимки, но не запускала обновление управляемых подключений.
5. Настройки Google локально находились в окружении, а в production соответствующие отдельные переменные отсутствовали. Название транзитного листа — «Заказы», а не значение по умолчанию «Транзит».

## Резервная копия и сохранность

До изменений сделан экспорт `artifacts/source-recovery/connections-before.json` (права 0600): идентификаторы, названия, состояния, конфигурация и определения связей. Секреты, шифротексты, пароли и переменные окружения не экспортировались. Папка исключена из Git и deployment. Исходно в базе было два подключения и две связи FinTablo; они сохранены. Секреты не менялись, ключ шифрования и окружение не изменялись.

Миграция 002 заменяет ограничение глобальной уникальности на отдельный идентификатор строки. Она не удаляет подключения, связи, снимки или журналы. Перед повторным применением `scripts/recover-sources.cjs --apply` делает новый экспорт. Для отката можно восстановить config и definition только затронутых идентификаторов из экспорта, сохраняя текущие секреты в базе. Возвращать старое ограничение уникальности при наличии нескольких связей нельзя.

## Источники и правила

- Существующий FinTablo: ДДС `/v1/transaction`, остатки `/v1/moneybag`; добавлено назначение финансовых записей `/v1/pnl-item`. За проверенный период API не вернул записей ОПиУ; нулевые/тестовые записи не создавались. Отдельный существующий аналитический отчёт Google ОПиУ сохранён, ему доступен сохранённый сервисный аккаунт.
- Google Sheets: существующая таблица из `DEBT_GOOGLE_SHEET_ID`, листы «Заказы» и «Склад». Подключение сохранено в панели с прежним сервисным аккаунтом (реквизиты зашифрованы). Названия листов сохранены в конфигурации. Серверные переменные при наличии сохраняют прежний приоритет.
- Кредиторка: в доступной таблице нет «Кредиторка по Заводу (1с)»; «РД_ПОСТАВЩИКИ» не содержит колонки суммы/остатка. Проверена также существующая таблица ОПиУ — этого листа в ней нет. Добавлен самостоятельный набор «Кредиторская задолженность» с обязательными полями поставщика и остатка; требуется указать настоящий лист. До этого показывается точный красный алерт и отсутствие данных, без подстановки нуля.
- Разные показатели независимы. Основной источник выбирается по приоритету (меньшее число выше), резерв используется при недоступности основного. Пустой успешно прочитанный набор считается настоящим результатом, а не ошибкой.
- Объединение работает для строк, исключает одинаковые нормализованные записи; суммы снимков остатков не складываются. Неполное объединение не выдаётся за полный итог. Для остатков доступны основной и резервный источники.
- Сохранение конфликтующих назначений объясняет конкретные раздел, показатель и источники. В редакторе доступны режим и числовой приоритет. Чужие связи больше не удаляются.
- Дебиторка читается заново; действует прежний FIFO внутри источника и ключа. Пустые/нечисловые остатки и строки без даты отгрузки диагностируются по прежнему регламенту. Знак суммы, пробелы и ₽ обрабатываются. Точные повторы строк в одинаковой схеме учитываются один раз; разные заказы с одинаковой суммой не отбрасываются только по сумме. Строки с разными схемами без общего идентификатора не объявляются дублями предположительно.
- Живой расчёт дебиторки не складывается повторно с готовым агрегированным реестром. «Направление» и «Признак» необязательны в универсальном сопоставлении; в исходном складском расчёте «Направление» остаётся установленным ключом FIFO.
