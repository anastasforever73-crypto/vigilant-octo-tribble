# Доступ к приложению через Codespaces: порт 3100

Проверено 18 сентября 2026.

## Повторная проверка после продолжения работы

На момент повторной проверки процесс из предыдущего отчёта отсутствовал: на 3100 не было слушателя, GET и POST возвращали ошибку соединения (HTTP 000). Приложение повторно запущено независимым процессом Next.js, PID 4181, с `PORT=3100`, адресом привязки `0.0.0.0:3100` и журналом `/tmp/mart-trade-3100.log`. Процесс не привязан к временному терминалу; остановка самого Codespace всё равно завершит его.

После запуска GET `/login` возвращает 200; POST `/api/auth/login` с пустым JSON возвращает 400 и соответствующую запись `AUTH_LOGIN` в журнале. Заголовки прокси Codespaces принимаются, посторонний Origin отклоняется с 403. Форма открывается в локальном браузере. Все 22 теста `node tests/core.test.cjs` проходят. Код авторизации и `.env.local` в этой повторной проверке не менялись.

Реальный внешний адрес проверен браузером: приватный порт перенаправляет на GitHub `pf-signin` (HTTP 302). В текущей браузерной сессии нет авторизации GitHub. Автоматическая проверка безопасности отклонила использование унаследованного GitHub-токена, токен не отправлялся. Успешный вход действующим аккаунтом и переход в дашборд через внешний адрес в этой проверке не подтверждены; пользователю предложено выполнить вход в своей браузерной сессии без передачи пароля. Ниже сохранены результаты предыдущей проверки, а не свидетельства текущего запуска.

## Причины

1. В начале проверки на 3100 не было слушающего приложения. GET `/login` и `/api/auth/login` завершались `curl: (7) Couldn't connect to server`, HTTP 000. Предыдущий браузерный тест завершил свой временный сервер.
2. После запуска production-сервера на `0.0.0.0:3100` проверка Origin отклоняла реальные запросы с HTTP 403. Next.js формирует внутренний URL из адреса привязки. Дополнительно прокси Codespaces переписывает Host и Origin на `localhost:3100`, сохраняя внешний адрес в `X-Forwarded-Host`. Это подтверждено запросом браузера и временной диагностикой только имён хостов.

В форме нет старого абсолютного API на 3000: используется `/api/auth/login`. Значение 3000 в `codespaceOrigin` остаётся стандартом для обычного запуска Next.js; постоянный сервер явно получает `PORT=3100`.

## Исправление

- `app/lib/request-origin.ts`: поддержан внутренний bind-адрес `0.0.0.0`. Переписанный Origin принимается только при локальном целевом Host, совпадающем порте и точном внешнем хосте, вычисленном из серверного окружения. Произвольный `X-Forwarded-Host` не добавляет доверенных адресов.
- Для HTML-формы восстанавливается правильный HTTPS-адрес перенаправления.
- `app/api/auth/login/route.ts`: безопасные записи `AUTH_LOGIN` содержат только результат, статус, формат или роль после успешного входа. Реквизиты и cookie не выводятся.
- `npm run start:codespaces`: постоянный запуск на `0.0.0.0:3100` с `PORT=3100`.
- Приложение оставлено отдельным фоновым процессом PID 17907, лог `/tmp/mart-trade-3100.log`. Это состояние на момент проверки; процесс работает, пока действует Codespace. Временный диагностический preload из запуска удалён.
