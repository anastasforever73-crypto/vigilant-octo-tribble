# Март-Трейд — демонстрационная версия для Timeweb

Интерфейс и расчёты раннего дашборда восстановлены из реальных исходников.
Набор app/demo-data.json целиком синтетический; названия и суммы вымышлены.
Клиентские данные и секреты в этой независимой истории отсутствуют.

См. TIMEWEB-DEPLOY.md: настройка двух ролей, сборка, запуск и ограничения.

```sh
npm ci
npm run setup-auth
npm run build
npm start -- --hostname 0.0.0.0 --port 3000
```

Реальные источники отключены. Это ранняя версия, а не восстановление современных
модулей Excel, постоянных архивов и персонального реестра пользователей.
