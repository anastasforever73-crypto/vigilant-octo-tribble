## Изменения

- Постоянный блок «Требует внимания» в ДДС заменён иконкой у заголовка «Денежный поток». Прежний текст сохранён. Наведение, нажатие, клавиатура, Escape и нажатие вне подсказки поддерживаются.
- Сравнение ДЗ использует существующие даты и переключатель «Сравнить». Остатки сравниваются на конец выбранного и предыдущего периода одинаковой длины. Дневные остатки не суммируются, текущая ДЗ не восстанавливает историю. Показаны рубли и проценты; отсутствующий снимок и нулевая база процентов имеют разные объяснения.
- В администрировании основные действия выделены существующим зелёно-бирюзовым цветом, опасные — красным контуром. Удаление, отключение и удаление связи требуют подтверждения. Отмена не отправляет запрос изменения.
- Добавлен отдельный блок «Ключевые показатели». Существующие разделы, подключения, авторизация и формулы сохранены.

## Источники новых показателей

| Показатель | Источник и правило |
|---|---|
| Расчётные счета | Сохранённое подключение «ФИНТАБЛО», `/v1/moneybag`, активные видимые банковские счета, без кошелька и депозита |
| Кошелёк | То же подключение; реальный счёт «Кошелек» |
| Депозит | То же подключение; реальный счёт «Т-Банк депозит» |
| Общий остаток | Однократная сумма активных видимых рублёвых счетов с числовыми остатками |
| Общая ДЗ | Google Sheets, действующие листы «Заказы» и «Склад», полный результат существующего расчёта после зачётов, копейки → рубли |
| КЗ НЛПК | Действующая схема: лист кредиторки по заводу, дата A и остаток G. Общая кредиторка всех поставщиков не подставляется |
| Отгрузки за вчера | «Заказы»: «Дата УПД» / «Ст-ть заказа»; «Склад»: «Дата отгрузки» / «сумма». Включены оплаченные строки, повторные строки исключены по существующему правилу |
| Выручка за вчера | FinTablo `/v1/transaction`, входящие операции с явной статьёй выручки / продаж / оплаты покупателей. В реальном источнике подтверждена статья «Оптовая продажа БН». Займы, возвраты и внутренние переводы не включены |
| Сравнение ДЗ | Полные снимки «Архива ДЗ» на конец каждого периода; для сегодняшней даты — текущий полный расчёт |

Предыдущий календарный день определяется по `Europe/Moscow` независимо от верхнего фильтра периода. Чтение счетов использует существующий выбор счетов и приоритеты подключений; настройки источников не записываются. Пустые/нечисловые значения не превращаются в тестовые суммы или нули в новом блоке.

При контрольном чтении доступны все новые показатели, кроме КЗ НЛПК: лист «Кредиторка по Заводу (1с)» отсутствует. Полных архивных снимков ДЗ нет. Для этих случаев интерфейс показывает отсутствие данных и причину.
