# Дебиторка: соответствие Otchet_DZ.gs

Проверено 18.09.2026. Этот отчёт заменяет прежние выводы о блокировке итогов из-за пустых остатков в `RECEIVABLES-IMPLEMENTATION.md`.

## Правила

- Исходные `toNumber` / `toDate` воспроизведены для строк текущего источника: пустое и нечисловое значение даёт 0; числовой префикс строки разбирается через `parseFloat`; даты разбираются с теми же допусками и календарными переносами.
- Нулевые остатки не входят в ДЗ. Ненулевые остатки без даты и после даты отчёта исключаются, но не блокируют расчёт остальных строк.
- FIFO, группировка внутри каждого источника, четыре категории, авансы и порог 0.005 руб. соответствуют исходнику. Денежная арифметика выполняется в рублях, как в скрипте; итоговые значения API переводятся в копейки.
- Поиск заголовков ограничен тем же диапазоном, сначала проверяется подсказка 19 / 9; для повторных названий берётся первое вхождение.
- Отчёт на 18.09.2026 использует период отгрузки 11–17.09.2026, как `buildForDate`. `runWeekly` исходника сначала выбирает прошедший понедельник; для сравнения датой обоих расчётов явно выбрано 18.09.2026.
- Пустые строки и строки с данными только вне четырёх сопоставленных колонок не попадают в диагностику. Дополнительного требования заполнять их нулями нет.
- Если один лист не прочитан, показывается сумма доступного листа с пометкой «Частичный результат», отсутствующий лист — «Нет данных». Если не прочитан ни один лист, суммы не показываются.
- Для исключений доступна полная построчная таблица: лист, номер строки, причина, исходные дата/остаток, сумма по правилу скрипта и ключ группировки. Есть поиск и пагинация. Нестандартные даты, принятые исходным скриптом, отмечены отдельным предупреждением.

## Границы и исключения

«Заказы»: заголовки в строке 1, последняя занятая строка 10078; дата N, сумма отгрузки L, остаток W, ключ D. 653 строки содержат данные только вне этих колонок; ни одна не попала в диагностику. Найденная строка с подписью итога 573 имеет нулевой остаток и не увеличивает ДЗ.

«Склад»: заголовки в строке 4, последняя занятая строка 6927; дата R, сумма H, остаток T, ключ K. 2540 строк с данными только вне этих колонок не попали в диагностику. Строк с явной подписью итога не найдено. Исходник не выделяет итоги по произвольным текстам; новая фильтрация по догадкам не добавлялась.

- «Заказы»: 132 пустых и 17 текстовых остатков приняты за 0; 237 строк без распознаваемой даты исключены на 83 717 976,00 руб. согласно исходнику как неотгруженные заявки.
- «Склад»: 150 пустых остатков приняты за 0; строки 4192 и 4193 без даты исключены на 231 316,00 руб.
- Всего в построчной таблице исключений: 538 строк. Соседние таблицы и полностью пустые строки в этот счётчик не входят.
- Один пустой ключ «Склада» включён в общую группу по правилу скрипта, а не исключён.

## Ограничения

- В «Заказах» строки 9035 и 9036 содержат `19.09-20.09` и `23.09-24.-09`. Исходник распознаёт их как 19.09.2020 и 23.09.2024. Они добавляют 1 116 000,00 руб. в категорию «Безнадежная». Теперь дашборд делает то же, с предупреждением. Это соответствие алгоритму, а не подтверждение бизнес-смысла этих дат.
- «Архив ДЗ» отсутствует: историческая динамика и сравнение с прошлой датой не выдумываются. Строгие проверки полноты архивных снимков сохранены.
- Снимок отражает момент чтения, текущие остатки не восстанавливают прошлые даты. В строках данных снимка нет дробных числовых дат; служебное дробное значение «Склада» находится выше заголовка и не участвует в расчёте.
- Безопасная Map-группировка сохранена для ключей вроде `__proto__`, на которых исходный объект Apps Script падает. Нефинитные и выходящие за безопасный числовой диапазон итоги не выдаются за денежные суммы.
